# Onboarding
A repo to host MDEL onboarding materials

## How to edit repo

1) Make sure that you have R, RStudio, and Git installed. Also make sure you have an active GitHub token associated with your R session. For more help, see these [Installation instructions](https://malone-disturbance-ecology-lab.github.io/Onboarding/installation.html).

2) Make sure that you have [Quarto](https://quarto.org/) installed as well.

3) [Clone the repo](https://malone-disturbance-ecology-lab.github.io/Onboarding/workflow.html#cloning-to-your-local-computer) to your local computer.

4) Make your edits as needed on RStudio. 

5) [Stage your local edits, commit them with descriptive commit messages, pull, then finally push to GitHub](https://malone-disturbance-ecology-lab.github.io/Onboarding/workflow.html#pushing-a-local-edit-to-github). This repo already has a [Quarto GitHub Action](https://quarto.org/docs/publishing/github-pages.html#github-action) workflow associated with it so you do not need to render and push the html pages to GitHub. It's already sufficient enough to push just the edited `.qmd` files to GitHub because the GitHub Action will automatically render them.
